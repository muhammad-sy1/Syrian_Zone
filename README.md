# تعليمات بناء تطبيق الـ APK
1. قم بفك ضغط هذا الملف على بيئة Linux أو Termux المدعومة بـ Buildozer.
2. تأكد من وضع توكن البوت الخاص بك داخل ملف `main.py` في متغير `token2`.
3. لتوليد ملف الـ APK، قم بتشغيل الأمر التالي في التيرمينال:
   `buildozer -v android debug`
4. سيتم إنتاج ملف الـ APK جاهزاً في مجلد `bin/`.
